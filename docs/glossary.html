2026 register

Legend

Portfolio language used in the register. Head product is the commercial environment; CPO and TPO are people.

Platform
The commercial environment the line belongs to. Sub-products are used only inside that platform. Standalone products can be sold independently and may be used on several platforms.
Head Product
Earlier name for Platform. A product may have more than one platform.
Universal Cloud
UGT’s universal cloud / virtual data centre platform.
Public Cloud
Public cloud environment / platform.
Private Cloud
Dedicated private cloud environment.
Colocation
UGT data-centre colocation offers.
Bare Metal
Physical dedicated server and appliance portfolio.
SMB
SMB-focused packaged cloud and services portfolio.
Standalone
Product that can be sold independently of the cloud platforms above.
ALL / Cross-portfolio
Cross-portfolio service applicable across platforms.
Type — Product
A sellable offer in its own right.
Type — Sub-Prod
A capability used only inside its parent platform, not sold as a standalone offer.
Category
Commercial grouping, for example Cloud Platform, VPS or Object Storages.
Class
Technical class, for example Compute, Network, Storage or Backup.
Features
Short tags for notable capabilities of the line.
CPO — Commercial Product Owner
The person accountable for the commercial offer: positioning, packaging and go-to-market.
TPO — Technical Product Owner
The person accountable for technical delivery, architecture and operational readiness.
Production
Live / operational product.
Pre-Production
Final preparation before production.
Development
Actively being built.
Pre-Development
Concept, discovery or preparation before development.
Deployment
Being rolled out / deployed towards production.
Wishlist
Wanted or planned product, not yet in delivery.
Pipeline
Planned product / backlog item.
Terminated
No longer active in the portfolio.
In Delivery
Executive roll-up of Pre-Production, Deployment and Development.
Due Date
Target year and quarter from the register, for example 2026 Q4. Unscheduled means the team has not set one yet.
PDDF Phase
Product definition and delivery phase from the register.
PDDF — Discovery
Early exploration of the offer.
PDDF — HD (High Level Design)
High Level Design — the solution is being designed at a high level.
PDDF — Solution
The solution is defined and being prepared.
PDDF — Pilot
A pilot or limited rollout is under way.
